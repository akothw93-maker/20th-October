setting up a Github repository for the first time

When setting up a Github repository for the first time,you need the following steps

  • Git init
  • Git add .
  • Git commit -m
  • Git branch -M main
  • Git remote add origin
  • Git push -u origin main

Updating a Github repository

When updating a Github repository or pushing to an existing repository,we use the following steps

  1. Git add .
  2. Git commit -m
  3. Git push
